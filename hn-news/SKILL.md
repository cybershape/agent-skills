# Hacker News 资讯与讨论助手 (hn-news)

本 Skill 用于使用 `ghn` CLI 抓取并结构化总结 Hacker News 的热门资讯、历史精选与深度评论讨论。

## 输出语言与基本原则

- **输出语言**：统一使用**中文**进行翻译与总结。
- **信息提取**：列表阶段保留原帖得分（Points）、评论数（Comments）与 ID，**禁止返回任何 URL 链接**；单篇深度解读阶段再提供完整原文链接与 HN 讨论链接。
- **客观准确**：忠于原文与讨论主旨，提炼核心论点、争议焦点与社区高赞洞见。

## 编号规范（必须严格执行）

在输出列表总结时，针对不同来源采用专用前缀编号：
- **Top 列表**：使用 **T1, T2, T3 ...** 编号
- **Yesterday 列表**：使用 **Y1, Y2, Y3 ...** 编号
- **Last Week 列表**：使用 **L1, L2, L3 ...** 编号

## 核心操作与流程

### 1. 列表获取与简要总结

根据用户需求执行对应的 `ghn` 命令：
- **获取当前 Top 榜单**：`ghn top`
- **获取昨日热门**：`ghn yesterday`
- **获取上周热门**：`ghn lastweek`

**抓取原则**：
- 列表阶段**无需 fetch 每篇文章的原文**，基于标题、链接及背景知识直接生成简要摘要，保证响应速度。
- 列表展示时**不要返回任何链接**（标题仅以纯文本加粗呈现，不带超链接）。

**列表输出格式规范**：
```markdown
[前缀编号]. **原标题英文** (xx points / xx comments, ID: xxx)
   - 中文核心摘要：1~2 句话提炼文章核心内容、背景及价值。
```

### 2. 单篇深度解读与评论总结

当用户要求“总结某一条”、“总结评论”、输入 `detail` / `more about`，或指定编号（如 `T9`、`L1`、`12`）或 HN ID 时：
1. **获取信息**：
   - 执行 `ghn comments <HN_ID>` 获取 HN 社区讨论。
   - 使用网页抓取工具（如 `web_fetch_exa`）获取该条目对应的文章原文。
2. **结构化输出**：
   - **元数据**：标题、作者、原文链接、HN 讨论链接、点赞与评论数。
   - **文章核心主旨**：背景痛点、核心技术/观点、关键结论。
   - **社区讨论焦点**：提炼赞同观点、反方意见、精彩延伸讨论或高赞真实经历。
   - **高价值片段提取**（如有）：按需提取用户讨论中分享的高价值 Prompt、代码片段或配置文件。
